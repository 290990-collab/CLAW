# Copy voice — a replaceable default

If the `## Project context` block of `copywriter` declares a different voice, **that one wins**.

- First person: whoever writes is someone, not a department.
- Short sentences, one idea per sentence.
- The point in the first line: whoever stops there must have understood what this is.
- No jargon — a technical term comes in only if the audience already uses it.
- Clear before clever: wit enters where it comes naturally, never forced.
- Concrete: what happens to the reader, not what the product does in the abstract.
- No hashtags, no decorative emoji, no emphatic capitals.
- Understood on the first pass, including by someone who does not know the field.
